# Frontend de PurchaseFlow

Aplicación React + TypeScript. El [README principal](../README.md) es la fuente oficial de documentación.

## Desarrollo

Configure `VITE_API_BASE_URL` en `.env` usando `.env.example` como referencia y ejecute:

```bash
npm install
npm run typecheck
npm test
npm run build
npm run dev
```

El selector ES/EN usa diccionarios tipados y React Context. `/mock-mail` es exclusivamente demostrativo y no debe exponerse públicamente en producción.
